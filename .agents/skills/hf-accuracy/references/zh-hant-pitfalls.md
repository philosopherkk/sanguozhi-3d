# 正體字高頻錯碼位速查（寫入前必對）

小模型寫正體中文時，下列字最常出現同音或相近碼位錯字，改寫時請直接從同檔既有詞彙複製：

- 正確用字：`將`（非 `将`）、`隊`（非 `堤`）、`潰`（非 `潫`）、`擱`（非 `搁`）、`無`（非 `沥`）
- 正確用字：`查`（非日文新字 `査`）、`冊`（非 `册`）、`鹽`（非 `塩`）、`圖`（非 `図`）、`關`（非 `関`）
- 兩用字須依詞義判定，不可整檔批次取代：
  - `准`＝許可（批准、核准、不准）／`準`＝標準預備（準備、準確、準則）
  - `后`＝皇后、太后／`後`＝前後、後來
  - `里`＝里程、鄉里／`裡`＝裡面、內裡
  - `台`＝台州、`台北`、`台海`（依本庫裁定保留）／`臺`＝臺灣、臺閣
  - `征`＝征伐、東征／`徵`＝徵兵、徵收

每次 commit 前必跑：
1. `node scripts/agent-selfcheck.mjs origin/main`（核對印出的「新出現的漢字」）
2. `npm run audit:chars > /tmp/chars.log 2>&1; echo exit=$?; tail -n 10 /tmp/chars.log`
