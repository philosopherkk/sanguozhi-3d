# 亞太戰區底圖（1931–1945）

三國／日本時代嘅地圖用兩張 relief 底圖（中國 1968×1567、日本 1482×1477）。
**呢兩張都Cover唔到大東亞共榮圈**：新加坡、荷屬東印度、緬甸、中途島、阿留申
全部喺畫面之外，所以戰爭時代要另外一張闊啲嘅亞洲—太平洋底圖。

## 邊度嚟

| | |
|---|---|
| 資料 | Natural Earth 1:50m 陸地（`world-atlas@2/countries-50m.json`，公有領域） |
| 生成 | `node scripts/gen_asia_war_base.mjs scripts/.cache/countries-50m.json` |
| 輸出 | `src/geo/asiaWarBase.ts`（陸地 SVG path + 經緯網 + `asiaPx(lon,lat)`） |
| 原始檔 | `scripts/.cache/countries-50m.json`（756KB，喺 .gitignore 之外唔入 repo） |

用**合併後嘅 land**而唔係國家多邊形：唔想將今日嘅國界帶入歷史地圖。

## 坐標系

等圓柱投影，畫布 1710×1000，畫面經 **60–190°**、緯 **−14–62°**。
經度先正規化入 `[60, 420)`；每個環如果跨度超過 180°，會把遠端帶嘅點減 360°
令成環連續（`unwrapRing`）。呢一步係必須嘅：張圖跨過 180°（中途島 177°W），
環如果唔處理，會拖出一條橫跨太平洋嘅假陸帶，even-odd 填充會把成個海變成陸。

`asiaPx(lon, lat)` 俾資料檔用：**所有勢力範圍、航路、行軍都照經緯度定義**，
再由渲染層 `clipPath` 夾喺海岸線之上，所以色塊唔會溢出入海。

## 點樣驗證

```
node scripts/gen_asia_war_base.mjs scripts/.cache/countries-50m.json --preview
```

- 14 個地標測試：新加坡、雅加達、曼德勒、英帕爾、東京、那霸、臺北、塞班、
  阿圖島、達爾文內陸、科倫坡應該係陸；中途島、珍珠港、威克島應該係海。
- ASCII 預覽（`--preview`）將陸地柵格化出嚟，冇圖都得睇shape。

而家 14/14 通過，資產 119KB（`TOL=0.9` px 簡化容差；再粗會抹掉細島）。
