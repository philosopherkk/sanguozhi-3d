## 6. 教訓清單（每條都交過學費）

1. **Runner 死喺收尾**：做晒內容但未 commit／push 就完咗（兩次）。派工必須「每 2–4 條 commit＋push」寫入指令。
2. **開放式跨模組任務連續零交付**：同一 runner 對「286 段跨包」兩輪零產出；收窄成「單檔＋明確 id 佇列＋一輪做得切」後四輪全交收。
3. **簡體字 IME 殘留反覆出現**（条/為/們/組織/后三條…）：寫完中文即刻跑 chars；呢個正正係 chars 閘門唔能松嘅原因。
4. **自己嘅驗證工具都會錯**：並行 curl 俾 rate-limit（429）誤判死鏈；`urlopen` 冇 CA；percent-encode 漏 title 參數。**判斷「死鏈」之前先證明自己嘅方法冇錯**（批量 `titles=` API 係標準做法）。
5. **HTTP 200 ≠ 條目存在**：`zh.wikipedia.org/zh-tw/<變體>` 對冇此條目嘅標題都會回 200。
6. **中文維基 canonical 可能係簡體字標題**（「庄园」），簡繁混寫（「庄園」）兩邊都唔存在。
7. **fixed 必然自成 stacking context**：視窗內文逃唔過更高 z-index 嘅兄弟層（§3-2）。
8. **堆疊 PR 鏈**：base 合併刪分支 → child 自動 closed；先合併→fetch→rebase child→（必要時）重建 PR。
9. **gitignore 檔喺 worktree 唔存在**（.env 事件）：凡要俾多個 worktree／排程 agent 用嘅嘢，放**絕對路徑**（~/.exa_api_key 模式）。
10. **自我測試多次救場**（BCE 世紀分桶 bug、war-shape 矩形偵測、reading-layers 退化）：新閘門必須附 `--selftest`，而 selftest 要識得「唔誤報合格樣本」。
11. **口徑不同嘅兩個閘門數字可以同時啱**（jpGap vs 比例 gap）：報告數字要連口徑一齊講。
12. **rebase 未合併嘅堆疊會製造假衝突**：先合併 base 層再 rebase（犯過一次，abort 後按協議順序重做即清）。
13. **「本倉→本條」式錯字可以入 main**：合併前自己 grep 一次錯字係免費嘅。
14. **查證輪嘅價值持續得到證明**：虛構書名／人物累計 ≥8 個全部由佢挖出；發現虛構文獻要即刻升格為工作單規則。
